# Calculadora de factorial

Programa sencillo en JavaScript que calcula el factorial de un número entero no negativo. El resultado se muestra en la consola del navegador; si el valor ingresado no es válido, se informa el error en esa misma consola.

## Cómo usarlo

1. Abre `index.html` en un navegador.
2. Escribe el número cuando aparezca la ventana de entrada.
3. Consulta el resultado en la consola del navegador (por ejemplo, con `F12`).

El programa valida que el valor sea un entero mayor o igual a cero. Recuerda que `0! = 1`.

## Archivos

- `index.html`: carga el programa en el navegador.
- `factorial.js`: valida el valor ingresado y calcula el factorial.

No se necesitan dependencias ni instalación.
